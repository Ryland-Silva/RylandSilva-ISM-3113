# RylandSilva-ISM-3113

## APEX — Inside the Race

A responsive, fan-made Formula 1 editorial landing page built with plain HTML, CSS, and JavaScript. It includes a custom vector racing-car illustration, race-weekend countdown, sample calendar cards, mobile navigation, and responsive layouts.

## Run it

Open `index.html` in a browser, or use the VS Code Live Server extension for local preview. No build step or package installation is required.

## Customize

- Update the sample race information in `index.html`.
- Change the race countdown target in `app.js` to match the featured weekend.
- Adjust colors and layout in `styles.css`.

Race dates and event details are sample content and should be verified before publication. The page uses Google Fonts when online and falls back to system fonts otherwise.
